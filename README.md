# Almoxarifado da Piramba

Controle dos itens da casa — estoque, validades por lote, alertas de vencimento e lista de compras —
compartilhado entre até 5 pessoas. App web (PWA) com Firebase.

- Endereço: https://felippealvarez.github.io/almoxarifado-piramba/
- Configuração: veja `GUIA-CONFIGURACAO.md`
- Manual, termos, privacidade e créditos: `info.html`

Enquanto `js/config.js` não tiver os dados do Firebase, o app roda em **modo demonstração**
(dados simulados, só no aparelho).
